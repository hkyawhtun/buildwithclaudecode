# Implement Project Todos

Start by reading `TODOS.md` in the project root. Present the list to the user so they can see what's coming. Then implement each item one at a time — read only the specific source files needed for that item before making changes.

## Constraints

- Do not change the visual identity of existing elements — extend, don't replace
- Do not add any new dependencies
- All new CSS goes in `src/index.css` using the existing CSS variables
- Keep changes minimal and focused — one item at a time

## Verify

After implementing all items, confirm each one works in the browser and nothing existing is broken.
